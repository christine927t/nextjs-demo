# Sitecore Content SDK Next.js Sample Application

## Overview

This is the basic Next.js app I used to create a marketing landing page. It includes reusable components and type declarations with optional content which could be used with Sitecore/CMS-driven content. 

## How to Run This Starter Locally

From the repo root:

```bash
npm install
npm run dev
```

Open **http://localhost:3000**.
